# Hanging_man-program-python
This is a simple hanging_man program built with python. Guess the hidden word one at a time before you run out of attempts.

# Features
- Random word selection
- ASCII hangman artwork
- Letter-by-letter guessing
- Detection of repeated and invalid guesses
- Win and lose conditions

# How to Play
1. Run the program.
2. Enter one letter when prompted.
3. Keep guessing letters to reveal the hidden word.
4. Win by guessing the complete word before you run out of attempts.

This project helped me practice Python functions, loops, conditionals, sets, modules and random selection.
